* OCaml tooling

1. =ocamlc= - bytecode compiler
2. =ocamlopt= - native code compilers
3. =ocamlfind= - frontend to the compiler ?
4. =dune= - build system so we don't have to use =ocaml{find,c,opt}= manually ourself.
5. =opam= - package manager
6. =utop= - REPL
7. =ocamlformat= - formatter
8. =ocaml-lsp-server= - duh

https://ocaml.org/docs/using-the-ocaml-compiler-toolchain
